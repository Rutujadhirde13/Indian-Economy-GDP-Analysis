##Indian Economy and GDP Analysis

A data analysis and visualization project focused on understanding India's economy and GDP growth using data wrangling, exploratory data analysis, machine learning, Excel, and Power BI.

Project Overview

This project analyzes Indian economic and GDP data to identify trends, patterns, and insights related to India's economic growth.

The project workflow includes:

- Data collection and preparation
- Data wrangling and cleaning
- Exploratory Data Analysis (EDA)
- GDP and economic trend analysis
- Machine learning analysis
- Data visualization and dashboard development

Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Microsoft Excel
- Power BI

Project Files

- "Dashboard for Indian Economy and GDP" – Power BI dashboard project
- "Data Wrangling in India" – Jupyter source file for data cleaning and EDA
- "Dataset Indian Economy and GDP Growth" – Excel dataset
- "ML Algorithm Analysis for Indian Economy" – Jupyter source file for machine learning analysis
- "Desktop" – Supporting project source/configuration file

Objective

The objective of this project is to analyze India's economic and GDP growth data, perform data preprocessing and exploratory analysis, apply machine learning techniques, and present meaningful insights through visualizations and an interactive dashboard.

Key Areas

- Indian GDP growth analysis
- Economic trend analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Machine learning analysis
- Data visualization
- Power BI dashboard development
